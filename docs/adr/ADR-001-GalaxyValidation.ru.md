# ADR-001 — GalaxyValidation

**Статус: Accepted.**

[English](ADR-001-GalaxyValidation.md)

## Назначение и зависимости

Проверять и при разрешении нормализовать значения из CLI, HTTP, БД, файлов, конфигурации,
внешних API и вычислений. Компонент не интерпретирует транспорт, обязательность параметров,
бизнес-коды ошибок или GResult.

Пакет: denetorus/galaxy-validation. Пространство имён: Galaxy\Validation.
Runtime: PHP >=8.4 и denetorus/galaxy-date ^0.1.0 из Packagist, без локального path-репозитория.
Для разработки: phpunit/phpunit ^13.4.

## Публичный API

- GValidator::validate(mixed $value, ValidationRule $rule): ValidationResult.
- ValidationRule(string $type, bool $strict = true, array $options = []).
- ValidationResult::success(mixed $value), failure(array $violations), isValid(): bool, value(): mixed.
- ValidationViolation(string $reason, string $expectedType, int|string|null $key = null).

Скалярные правила: string, integer, float, boolean, date-string, datetime-string, datetime, timestamp, mixed.
Для каждого правила существует форма array[T], включая array[mixed].
Имена правил регистрозависимы.
Поддерживаются только перечисленные имена правил. Вложенные правила, схемы и объединения типов не предусмотрены.

Непустые options допустимы только для date-string, datetime-string, datetime, timestamp и их форм array[T].
Для остальных правил options должен быть пустым; иначе конструктор ValidationRule вызывает InvalidArgumentException.

## Строгость и нормализация скаляров

По умолчанию strict:true: значение уже должно иметь требуемый тип.
strict:false дополнительно разрешает описанные преобразования, а не сохранение исходного типа.
Вход не изменяется; успешное нормализованное значение читается через ValidationResult::value().

string принимает PHP-строки, включая пустые, в обоих режимах; другие типы в строки не преобразуются.
integer строго принимает PHP int. Нестрогий режим также преобразует целые ASCII-строки [+-]?[0-9]+.
Ведущие нули и плюс разрешены, пробелы нет. Значение должно входить в PHP_INT_MIN..PHP_INT_MAX.
Float, bool, null, дробная и экспоненциальная запись в integer не преобразуются.

float строго принимает конечный PHP float; NAN/INF/-INF запрещены.
Нестрогий float также преобразует PHP int и строки, целиком соответствующие
[+-]?(?:[0-9]+(?:\.[0-9]*)?|\.[0-9]+)(?:[eE][+-]?[0-9]+)?.
Пробелы, шестнадцатеричная запись и десятичная запятая запрещены; переполнение до бесконечности отклоняется.
Действуют округление и underflow PHP; точные десятичные значения и целые без потерь не гарантируются.

boolean строго принимает PHP bool. Нестрогий режим также принимает целые0/1 и строки "0"/"1"/"true"/"false".
Для true/false ASCII-регистр игнорируется, пробелы не удаляются.
Float (включая0.0/1.0), null, пустые строки, yes/no и другие целые запрещены.
mixed всегда успешен и сохраняет обычную семантику PHP, включая идентичность объектов.

## Календарные правила

| Правило | Строгий режим | Нестрогий режим | Успешное значение |
| --- | --- | --- | --- |
| date-string | Строка даты по format | Та же проверка строки | Исходная строка |
| datetime-string | Строка даты/времени по format | Та же проверка строки | Исходная строка |
| datetime | Только DateTimeImmutable | Также настроенное преобразование строки через GDate::toDateTime | DateTimeImmutable |
| timestamp | Только PHP int | Также настроенное преобразование строки через GDate::toTimestamp | PHP int, Unix-секунды |

Изменяемый DateTime не принимается правилом datetime ни в одном режиме.
Готовые DateTimeImmutable/int возвращаются без изменений, включая идентичность неизменяемого объекта.
Любой PHP int допустим как готовый timestamp; календарные и бизнес-ограничения не добавляются неявно.
Числовая строка не трактуется автоматически как секунды epoch.

date-string требует ровно options.format. datetime-string требует format и допускает offset/timezone.
Оба правила вызывают проверку GDate и сохраняют строку независимо от strict.
datetime-string требует время в формате; дата без времени в этом правиле не становится полуночью автоматически.

Для datetime/timestamp options может быть пустым при проверке готовых значений.
Нестрогое преобразование строки включается только с непустыми исходными настройками GDate.
Без этих настроек строка даёт type_mismatch, без угадывания формата.
Непустые options проверяются при создании ValidationRule через публичный API GDate;
неверные формат, ключи, зона или смещение вызывают InvalidArgumentException даже при strict:true.
Настройки относятся только к преобразованию строки и не ограничивают и не меняют готовые значения.

Формат преобразования может описывать только дату либо дату/время.
Дата без времени становится полуночью в явной исходной зоне/смещении.
Явное смещение в строке datetime можно задать через P.
Верная календарная строка без исходной зоны/смещения даёт timezone_required.
GDate проверяет пропуски/повторы местного времени, согласованность смещения и точность.
Ненулевые микросекунды дают precision_loss для timestamp, но сохраняются в объектах datetime.
GalaxyValidation не выполняет пересчёт зон, форматирование или обновление базы зон.

Календарные обозначения, точное соответствие, границы и переходы определяет принятый ADR GalaxyDate:
https://github.com/Denetorus/GalaxyDate/blob/v0.1.0/docs/adr/ADR-001-GalaxyDate.ru.md
GValidator использует только публичные методы GDate; календарная реализация здесь не дублируется.
Диагностика находится в Galaxy\Date\Diagnostics\TimezoneDatabase и не вызывается при валидации.

## Массивы и результаты

array[mixed] требует PHP array и принимает любые элементы, включая null, объекты и вложенные массивы.
Пустой массив допустим; сохраняются ключи, порядок, идентичность объектов и обычная семантика ссылок PHP.
Элементы не преобразуются; strict не влияет на результат. Не-массив даёт type_mismatch.

array[T] требует PHP array; пустой массив допустим. Ключи и порядок сохраняются.
Каждый элемент проверяется по T с общими options/strict.
Каждый неверный элемент даёт отдельное нарушение в порядке входа. Вложенные массивы допустимы для mixed и array[mixed]; остальные правила массивов их отклоняют.
Валидатор не упаковывает скаляр в массив.

Успех содержит весь нормализованный массив. При любой ошибке частичного массива нет.
Готовые неизменяемые элементы сохраняют идентичность; преобразованные элементы — новые объекты.
Для значений, ссылок и объектов действует обычная семантика PHP; глубокое копирование не вводится.

violations — упорядоченный список ValidationViolation; пустой список означает успех.
failure([]), не-list и элементы другого класса — ошибки конфигурации.
reason — машинная причина; expectedType — полное правило для верхнего уровня либо T для элемента.
key — null для верхнего уровня, иначе исходный ключ массива.
Неверные значения в нарушениях не сохраняются. value() при ошибке вызывает LogicException.
Успешный mixed может быть null. Отладочное представление скрывает значение; это не хранилище секретов.

Причины: type_mismatch, invalid_integer, integer_out_of_range, invalid_float, float_out_of_range,
invalid_boolean и причины GDate invalid_date, invalid_datetime, invalid_offset,
nonexistent_local_time, ambiguous_local_time, timezone_offset_mismatch, timezone_required,
precision_loss, timestamp_out_of_range.
Неверная конфигурация правила/результата вызывает InvalidArgumentException; неверные данные возвращают нарушения.

## Интеграция и проверки

Обязательность параметров, упаковка, бизнес-условия, тексты и коды GResult определяются вызывающей стороной.
Помощники GalaxyApplicationConsole записывают успешное нестрогое значение обратно в CommandInput.
Строковые календарные правила оставляют строку, datetime записывает неизменяемый объект, timestamp — int.
Сам валидатор не назначает коды4/4 или5/4 и не зависит от GalaxyResult, Console или контейнера.

Запуск: composer install, затем php vendor/bin/phpunit.
Тесты проверяют нормализацию скаляров, strict календарных типов, готовые значения, преобразования строк,
календарные/зональные/точностные ошибки, массивы и неизменность входа.
Опубликованный GalaxyDate устанавливается автоматически из Packagist.
